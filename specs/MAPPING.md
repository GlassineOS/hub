# ID mapping: `001-hub-app` → the ten specs

([README.md](README.md)). Code comments and commits on the PR branches cite the old IDs; each old
ID maps to exactly one new one. A new ID is written `NNN ID`: the spec number, then the ID inside
that spec (for example `FR-027 → 004 FR-008`).
